alisa-engine

Un motor 3D ligero con una puerta al gym: el mismo entorno se juega con una política numérica, con un LLM que razona en verbos, o con las manos.
Sin instalar nada, sin backend. Abres un .html y funciona. Motor completo + three.js ≈ 2,2 MB.

LAS TRES PUERTAS

Cada entorno se puede jugar de tres maneras, y las tres dan la misma puntuación — por eso son comparables entre sí.

puertainterfazpara quién
numéricareset(seed) · step(action) · getObservation()políticas, RL
lenguajedescribe() · affordances() · stepVerb()agentes LLM
humanala sala lo renderiza y lo juegaspersonas

LA PARTIDA ES LA PRUEBA

Una puntuación enviada por un desconocido no vale nada. Lo que vale es la partida: la semilla y la lista de jugadas. Con eso se vuelve a jugar exactamente la misma partida y se comprueba el resultado.

{ "juego": "blackjack", "semilla": 4085196618,
  "jugadas": ["hit","stand","deal","hit",…], "puntos": 2 }

Un zapato entero de blackjack —54 manos— cabe en 1 KB y se verifica en 0,5 ms. Y eso mismo es el conjunto de datos: como las reglas son deterministas, esos bytes se expanden en la trayectoria completa de estados y decisiones, que es la forma que pide el aprendizaje por imitación.

Funciona porque se cumplen dos condiciones, y las dos están medidas: las reglas son deterministas (mulberry32, solo enteros de 32 bits ⇒ idéntico en cualquier máquina) y son JavaScript puro — cero document, cero THREE. El mismo fichero que juega en el navegador verifica en el servidor.

QUÉ HAY DENTRO

soma/render e IO — AlisaRenderCore, plugins, assets. El backend es enchufable: WebGL hoy, WebGPU si lo pides
psyche/interfaz y decisión
world/simulación — factories, systems, ECS
gym/el contrato de las tres puertas + el puente a Python
arcade/js/protohub/las reglas locales, el verificador y el dataset

El núcleo es vainilla: no habla con ninguna red por su cuenta, y hay un guardián que lo comprueba (check_vanilla_boundary.py). Conectarse a ALISA es una mejora, no un requisito.

EMPEZAR

git clone <este-repo>
cd alisa-systems
python servir.py            # sirve public/ SIN caché, en :8000

Y abres la portada. No hace falta npm install para usarlo; solo para reconstruir el bundle.

Ojo con python -m http.server: no manda cabeceras de caché, el navegador se queda con los .js viejos y te enseña una versión distinta de la que tienes en disco. Cuesta horas de depuración fantasma.

LO QUE FALTA, DICHO

  • Backgammon y bestiario no tienen reglas en JavaScript todavía; en la sala están marcados EN OBRAS.
  • La clasificación es de modelos locales pequeños, y ellos solos no ordenan gran cosa. Hasta que no haya modelos grandes en las mismas filas, la tabla demuestra el método, no el techo.
  • 16 módulos de colonia siguen bajo src/. Funcionan aparte, pero ahí sobran.
